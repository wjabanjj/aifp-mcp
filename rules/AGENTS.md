# ai-cognition 自动记忆识别

本项目的 ai-cognition MCP 服务器提供记忆感知能力。为启用自动记忆识别，每次回复用户后请执行以下操作：

## 自动记忆规则

1. 用户发出消息后，你完成回答
2. 回答结束后，调用 `observe_turn` MCP 工具：
   ```
   observe_turn(user_message: "用户最后一条消息")
   ```
3. 系统会自动判断该消息是否包含值得记住的信息（偏好、事实、决策、错误、项目信息等）
4. 如果 `observe_turn` 返回 `{ queued: true }`，系统会异步识别并入库
5. 如果返回 `{ queued: false }`，说明是普通交流，无需处理

## 注意事项

- 不要代替用户调用 `save_memory` — 让自动识别决定什么值得记
- `observe_turn` 仅入队，不阻塞回答流程
- 识别由后台调度器批量处理（默认 30 秒间隔）
